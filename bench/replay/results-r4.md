# Replay study: real agent pull requests through `aver ci`

Generated by `node bench/replay/summarize.ts` from `results.jsonl` and the hand triage in `triage.json`. Failure analysis is in [findings.md](findings.md).

## Setup

- **Aver commit:** `1a0727d8642c` (`aver ci`, release build).
- **Date:** 2026-10-12 to 2026-10-13.
- **Machine:** Apple M1 Pro laptop (8 cores, 16 GiB), Docker Desktop (Linux VM with 8 CPUs and 8 GiB), `linux/arm64` sandboxes under hardened `runc`. gVisor was not installed, so `--sandbox auto` used `runc` for every run.
- **Invocation:** `aver ci --repo <bare clone> --base <recorded base> --head <PR head> --home <one persistent home> --fail-on never --sandbox auto`, one pull request at a time, with a 30-minute wall-clock limit each. Other Docker workloads (another agent's test suites and a local web stack) shared the VM during the runs, which matters for the timeout-driven flakiness in findings.md. No pull request has an `aver.toml`, so every run used Aver's default environment: the pinned `node:22-bookworm-slim` image, `npm ci --ignore-scripts`, and one check `npm test` with no JUnit report.
- **Rules:** round-3 verdict rules. No criteria were declared, so every receipt is regression-only (`aver.receipt/v1`): the verdict is `FAIL_OWN` for any `NEW`, `BLOCKED_NOT_OWN` for any `ENV`, else `PASS`. There is no transplant proof, and the harness (`package.json` scripts, lockfile, test config, the tests themselves) is taken from the head, so a pull request that edits its own tests or test script is judged by what it edited.
- **Base:** GitHub's recorded `baseRefOid` for the pull request (the base-branch tip it was last compared against). Where that commit is not an ancestor of the head, the diff Aver judges also contains the base branch's newer commits, reversed. The table marks those rows.
- **Dataset:** pull requests from AIDev (Hao Li, Haoxiang Zhang, Ahmed E. Hassan; https://huggingface.co/datasets/hao-li/AIDev, CC-BY-4.0), filtered to TypeScript and JavaScript repositories with an npm lockfile and a `test` script, then screened against GitHub. The manifest is [manifest.json](manifest.json). Code was fetched read-only from the public repositories.
