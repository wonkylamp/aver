Check a receipt

Paste or drop an Aver receipt to check its content id and signature, then see what the change fixed and what it broke. Everything runs in this page. Nothing is uploaded.

A bare receipt, the receipt.json the GitHub Action uploads, or the output of aver verify --json. Drop a file here or

From the action's public-key.txt, or the public_key field of $AVER_HOME/keys/server.json on the machine that issued the receipt. Without it, the page computes the id but cannot check the signature.

The example is a real receipt from the calc test fixture, signed by a throwaway local verifier key. Forge the verdict to see what tampering looks like.

Verification uses the canonical JSON, BLAKE3 id and Ed25519 signing rules of Aver's object store, bundled for the browser.

This page sets no cookies, has no analytics and loads nothing from other servers.
